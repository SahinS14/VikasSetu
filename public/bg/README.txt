# Background Images Folder

Upload or paste your new background image here!

Supported filenames for the login page background:
1. `background.jpg` (or `background.png`, `background.webp`)
2. `hero_people.jpg` (or `hero_people.png`)

Once you place your image here, you can name it `background.jpg` or let Antigravity know the filename so it can be linked immediately in `src/views/Auth/LoginView.tsx`.
